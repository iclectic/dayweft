# Analytics Event Catalogue

Analytics are optional and consent-based.

Never collect task titles, task notes, calendar titles, focus-session content or personal schedule descriptions.

Allowed privacy-safe events:

- `onboarding_completed`
- `first_plan_created`
- `block_created`
- `quiet_focus_session_completed`
- `reality_check_completed`
- `reweave_my_day_opened`
- `suggestion_displayed`
- `suggestion_accepted`
- `suggestion_rejected`
- `suggestion_undone`
- `calendar_connected`
- `template_applied`
