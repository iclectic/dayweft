# Android release

Dayweft is not ready for production submission. See [release blockers](audit/release-blockers.md) and [roadmap](ROADMAP.md).

The public Android label is Dayweft. The existing provisional ID `app.dayweft.dayweft_mobile` is preserved until the owner confirms ownership/registration. SDK target/compile are 36, minimum 24. Private SQLite/preferences are excluded from Android automatic backup and device transfer; manual exports remain the user's responsibility. Android OS/vendor behaviour must still be tested.

## Protected upload signing

Create an upload key using Android's documented release-signing process, keep it outside the repository, store an encrypted recovery copy and enable Play App Signing in the owner's console. Do not paste credentials into chat, CI logs or source files.

Create ignored `apps/dayweft_mobile/android/key.properties` locally with `storeFile` (absolute path to protected keystore), `storePassword`, `keyAlias` and `keyPassword`. Gradle refuses release tasks without complete configuration and never selects debug signing. The standard `androiddebugkey` alias is explicitly rejected. No upload key is generated by this change.

After owner confirmation of the application ID:

```sh
DAYWEFT_ANDROID_ID_CONFIRMED=yes bash scripts/build_android_release.sh
```

This runs `flutter build appbundle --release --dart-define=APP_ENV=production`. Keep the monotonically increasing build number in `pubspec.yaml` or pass `--build-number=<next>`; record version/commit/toolchain and hashes. Expected output: `apps/dayweft_mobile/build/app/outputs/bundle/release/app-release.aab`. No such signed artefact is claimed until actually built with owner credentials.

Verify signer identity, merged permissions/components, release install, shrinker behaviour, native symbols and 16 KB native alignment. Run release/profile device journeys, TalkBack and actual offline/calendar/notification/focus lifecycle tests. Do not publish on every push. Production deployment and Play upload/testing/rollout remain under owner control.
