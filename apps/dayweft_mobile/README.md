# Dayweft Mobile

Flutter app for Dayweft: Adaptive Day Planner.

This app currently contains the Phase 2 scaffold:

- Material 3 app shell.
- Bottom navigation for Today Timeline, Inbox, Quiet Focus, Your Rhythm and Settings.
- Initial Drift database schema.
- Local package links to the domain, design system and Adaptive Engine packages.

Run locally:

```sh
flutter pub get
dart run build_runner build
flutter test
flutter run
```
