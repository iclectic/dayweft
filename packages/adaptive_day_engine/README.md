# adaptive_day_engine

Pure Dart deterministic scheduling engine for Dayweft.

Implemented in the scaffold:

- Reality Check observations for overlaps, tight transitions, high utilisation, deadline misses and oversized unsplittable tasks.
- Reweave result shape with the three Dayweft alternatives.
- Explanation, trade-off and confidence fields.

This package must not depend on Flutter, Drift, Supabase or UI packages.
